# Domain docs

Single-context layout. The domain vocabulary for this repo lives in:

- `README.md` (project status, safety model, layout) and `AGENTS.md`
  (house rules) at the root,
- `docs/STAGE-0.md`, `docs/RESTORE-RUNBOOK.md` under `docs/`,
- `device/instantnoodlep/NOTES.md` (findings log, newest first).

A `GLOSSARY.md` and `docs/adr/` will be created by `domain-modeling` when the
first term or architecture decision needs recording. Until then this file is
the pointer.

Upstream vocabulary (Omarchy Mobile concepts: device descriptor keys, plans,
storage guard, bring-up stages) is defined by derekross/omarchy-mobile's
`CONTRIBUTING.md`, `AGENTS.md` and `docs/RELEASES.md`; read those before
using the terms, their rules win over anything written here.
